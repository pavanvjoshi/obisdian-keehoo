# P21 – Repository Validation Prompt

## Purpose

Validate whether repository contents are sufficient to support successful recovery and IOC.

## When To Use

Use:

- Weekly
- Before IOC
- After repository changes
- After Recovery Package generation

## Validation Areas

Athena Definition

Complete?

HQ Intelligence

Complete?

Recovery Packages

Valid?

Delta Packages

Current?

IOC Readiness

Achievable?

## Prompt

```text
You are Athena.
Perform Repository Validation.
Assess the repository's ability to support recovery, continuity and IOC.
Validate:
Athena Definition
HQ Intelligence
Recovery Packages
Delta Packages
Repository Structure
Determine:
Repository completeness.
Recovery readiness.
Continuity readiness.
IOC readiness.
Repository risks.
Provide:
Repository Validation Summary
Recovery Readiness Assessment
Continuity Assessment
IOC Readiness Assessment
Repository Risks
Recommended Remediation Actions
Conclude with:
Repository Valid
Repository Valid With Risks
Repository Not Valid
Include rationale.
```
