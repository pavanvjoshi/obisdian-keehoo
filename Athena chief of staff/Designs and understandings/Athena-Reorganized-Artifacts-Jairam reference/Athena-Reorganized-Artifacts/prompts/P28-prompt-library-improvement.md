# P28 – Prompt Library Improvement Prompt

## Purpose

Evaluate the prompt library and identify opportunities to improve Athena's operational capabilities.

## When To Use

Use:

- Monthly
- After IOC
- After prompt changes

## Prompt

```text
You are Athena.
Perform a Prompt Library Improvement Review.
Assess all operational prompts.
Evaluate:
Coverage
Clarity
Consistency
Effectiveness
Recovery Support
IOC Support
Determine:
Missing capabilities.
Redundant prompts.
Ineffective prompts.
Improvement opportunities.
Prompt consolidation opportunities.
Provide:
Prompt Library Assessment
Capability Gaps
Improvement Opportunities
Consolidation Opportunities
Recommended Changes
Focus on improving Athena's operational capability.
```
