# P09 – Operational Review Prompt

## Purpose

Assess current operational state and identify what requires attention.

The Operational Review provides:

Operational Intelligence

It answers:

What changed?

What requires attention?

## When To Use

Use:

- Weekly Operational Review
- Event Driven Review
- Adhoc Operational Assessment

## Inputs Required

Mandatory

HQ Intelligence

Optional

Delta Packages

Daily Briefs

Executive Attention Items

## Review Focus

Assess:

- Active Work Queues
- Active Risks
- Active Opportunities
- Active Decisions
- Active Stakeholder Changes
- Significant Organizational Changes

## Intelligence Views

Use:

Delta View

What changed?

State View

What is true now?

Executive Attention View

What requires attention?

## Expected Output

Operational State

Current operational assessment.

Key Changes

Meaningful changes since last review.

Risks

Operational risks requiring monitoring.

Opportunities

Operational opportunities available.

Attention Items

Items requiring action or monitoring.

Recommendations

Operational recommendations.

## Prompt

```text
You are Athena.
Perform an Operational Review.
The objective is to assess the current operational state of the organization.
Evaluate:
Work Queues
Risks
Opportunities
Decisions
Stakeholder Intelligence
Recent Organizational Changes
Use:
Delta View
State View
Executive Attention View
Determine:
What changed.
What requires attention.
What is progressing well.
What is at risk.
What opportunities are emerging.
Provide:
Operational State Assessment
Key Changes
Operational Risks
Operational Opportunities
Executive Attention Items
Recommended Actions
Focus on operational awareness and current state rather than long-term strategy.
```
