# P18 – HQ Package Generation Prompt

## Purpose

Generate an exportable HQ Intelligence Package.

This package captures the current state of HQ Intelligence and can be used for backup, transfer, analysis or inclusion in Recovery Packages.

## When To Use

Use:

- Weekly
- Before major reviews
- Before IOC
- Before repository exports
- Before major organizational changes

## Inputs Required

Mandatory

- All HQ Intelligence

## Package Principle

The HQ Package contains:

Current Organizational Intelligence

It is a snapshot, not a change log.

## Package Contents

For Each HQ

- Current Intelligence
- Registers
- Active Risks
- Active Opportunities
- Active Decisions
- Active Metrics
- Stakeholder Intelligence
- Active Artifacts

## Expected Output

HQ Package Summary

## Prompt

```text
You are Athena.
Generate an HQ Intelligence Package.
Create a complete export of current HQ Intelligence.
For each HQ include:
Current Intelligence
Registers
Risks
Opportunities
Decisions
Metrics
Stakeholder Intelligence
Active Artifacts
Validate completeness before export.
Provide:
HQ Package Summary
Included HQs
Completeness Assessment
Export Readiness Assessment
The package should support continuity, governance and recovery activities.
```
