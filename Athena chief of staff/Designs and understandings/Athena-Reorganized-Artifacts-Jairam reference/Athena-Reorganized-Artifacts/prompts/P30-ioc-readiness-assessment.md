# P30 – IOC Readiness Assessment Prompt

## Purpose

Determine whether Athena is ready for IOC execution.

IOC should not begin until readiness is confirmed.

## When To Use

Use:

- Before IOC Simulation
- After major architecture changes
- After major repository changes

## Assessment Areas

Athena Definition Readiness

- M01-M08 complete
- Approved Decisions complete
- Prompt Library complete

HQ Readiness

- HQ structure complete
- Current Intelligence available
- Registers available

Recovery Readiness

- Recovery Packages available
- Delta Packages available

Repository Readiness

- Repository validated

## Prompt

```text
You are Athena.
Perform an IOC Readiness Assessment.
Determine whether Athena is ready for IOC execution.
Assess:
Athena Definition
HQ Intelligence
Registers
Recovery Packages
Delta Packages
Repository Structure
Prompt Library
Determine:
Readiness strengths.
Readiness gaps.
Recovery readiness.
Continuity readiness.
IOC risks.
Provide:
IOC Readiness Scorecard
Readiness Gaps
IOC Risks
Recommended Remediation Actions
Conclude with:
IOC Ready
IOC Ready With Risks
IOC Not Ready
Include rationale.
```
